# UX-004 — Desempenho percebido e real

**Agente:** A06 — Student UX · **Modelo:** Sonnet 5.5 · **Esforço:** médio

## Objetivo
Páginas públicas (landing, catálogo, curso) e a área do aluno rápidas no celular 4G: bom LCP, pouco JS no cliente, imagens otimizadas, fontes sem bloquear o texto.

## Leia (somente isto)
- `CLAUDE.md`; `docs/backlog.md` → linha `UX-004`; `docs/architecture.md` (grep "cache", "Cache-Control")
- `next.config.ts` (headers, `images.remotePatterns`), `src/app/layout.tsx` (fontes), `src/components/brand/IsoCover*`, componentes que mostram capa (grep `cover_path\|coverUrl`)
- `node_modules/next/dist/docs/` só para `next/image`, `next/font`, cache/revalidate do Next 16

## Entregas
1. **Imagens:** capas de curso via `next/image` com `sizes` corretos e `priority` só na imagem LCP; nada de `<img>` cru para capas.
2. **Fontes:** `next/font` com `display: 'swap'`, só pesos/subsets usados (`latin`), preload só da fonte do texto principal.
3. **JS no cliente:** `npm run build` e liste First Load JS por rota; reduza `'use client'` desnecessário (componentes que só renderizam), `dynamic()` para o que é pesado e fora da dobra (ex.: editores do admin, dialogs). Registre antes/depois em `docs/ux-review.md` (seção "Desempenho").
4. **Cache de leituras públicas:** NÃO cachear nada que dependa de sessão. Catálogo e página do curso hoje são dinâmicas (usam cookies). Só proponha (não implemente) separar leitura pública cacheável, porque mexe na arquitetura de dados; escreva a proposta no relatório.
5. Medição: Lighthouse mobile (Chromium em `/opt/pw-browsers/chromium`; `npx lighthouse` só se já disponível, senão métricas via Playwright `performance` API) na landing e em `/dev/catalog` antes e depois.

## Não fazer
- Não mudar textos/rótulos visíveis nem `aria-*` (há uma suíte E2E em `e2e/` que usa esses textos).
- Não mexer em `actions.ts`, `queries.ts`, migrations, `src/lib/payments`, `e2e/`. Sem libs novas. Não editar `MASTER_PLAN.md`/`docs/changelog.md`. Não commitar.

`npm run lint && npm run typecheck && npm test && npm run build` verdes; números antes/depois no relatório.
