## Objetivo
Admin encontra alunos, vê o perfil (cursos com origem e progresso, pedidos) e atribui/remove cursos manualmente — sem nunca afetar uma compra ao remover uma atribuição.

## Entregas
- `src/features/students/{queries,actions,schemas}.ts` (+ testes).
- `/admin/alunos`: busca por nome/email (input com debounce que atualiza `?q=`, funciona também com submit sem JS), paginação server-side (`?pagina=`), tabela → cartões no mobile; vazio/erro/loading.
- `/admin/alunos/[id]`: dados (nome, email, data de cadastro), matrículas com selo de origem (Comprado/Atribuído), estado (ativa/revogada em cinza com motivo), progresso; pedidos (status, valor, data, reembolso solicitado + % consumido).
- "Atribuir curso": combobox/select de cursos publicados ou arquivados sem atribuição ativa → insert `admin_grant` com `granted_by` = admin atual.
- "Remover atribuição": `Dialog` com motivo obrigatório → update de revogação (`revoked_at`, `revoked_by`, `revoke_reason`) **somente** em matrícula `admin_grant`.
- "Revogar compra": ação separada, só em matrícula `purchase`, motivo obrigatório, texto de alerta ("use apenas após reembolso/fraude; o reembolso em si é feito em Pedidos").
